# Logo sources

Used only to name the companies and tools involved in this work. All trademarks belong to their owners.

- Most tool marks: simple-icons (CC0) and devicon (MIT), recoloured for a dark background.
- ibm, openai: simple-icons v11 (CC0). microsoft: the standard four-square mark.
- carleton: carleton.ca (cu-shield). vapi: vapi.ai navigation logo.
- jonas: vector trace of the logo on jonassoftware.com, wordmark only.
- glyph-*: drawn for this site.

After changing a file here, run `node scripts/build-logos.mjs`.
